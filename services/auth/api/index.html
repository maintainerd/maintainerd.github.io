API reference

Auth API

A product-level reference shell for Auth endpoint families. This page is ready for exact OpenAPI expansion as the public release stabilizes.

DocsAPI referenceAll services

Endpoint families

POSTSetup

Bootstrap platform setup, create the initial tenant, and prepare the Auth service for use.

GETTenants

Manage tenant records, memberships, ownership rules, and organization-level access.

POSTOAuth

Authorize clients, exchange tokens, handle consent, silent auth, and end-session flows.

GETUsers

Operate users, account status, profile data, sessions, and security state.

POSTClients

Register OAuth clients, first-party clients, redirect URIs, secrets, grants, and policies.

GETPolicies

Read roles, permissions, policy bundles, and service-to-service authorization rules.

POSTMFA

Enroll, challenge, verify, recover, and enforce multifactor authentication.

DELSessions

Clear local sessions, revoke tokens, and coordinate logout across identity surfaces.

Reference direction

As Auth approaches public release, this page should link to generated OpenAPI, SDK examples, OAuth flow diagrams, response schemas, and service-auth examples for other Maintainerd services.
