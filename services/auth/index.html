Identity & Access Management

Auth

A self-hostable identity and access platform for Maintainerd services and external applications. It provides OAuth 2.0, OpenID Connect, hosted login, user and tenant administration, MFA, sessions, policies, API keys, service authorization, audit events, and operational controls.
