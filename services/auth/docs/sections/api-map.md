# API Map

This section is the bridge from docs to the API reference.

## Public Identity API

- Tenant lookup.
- Client lookup.
- Login, logout, refresh token.
- Registration.
- Invite registration.
- Email verification.
- Forgot and reset password.
- Magic links.
- SMS login.
- MFA self-service and step-up.
- Account, profile, sessions, devices, settings, data export, and erasure.
- Federation and linked identities.
- OAuth and OIDC.
- Public branding.

## Internal Management API

- Setup.
- Tenants and tenant settings.
- Users, profiles, devices, consents, sessions, invites, and admin erasure.
- Identity providers and registration flows.
- Clients.
- Services, APIs, permissions, policies, roles, and authorization.
- Security settings and IP restrictions.
- Branding, email templates, SMS templates.
- Email and SMS config.
- Events, auth events, audit logs, and webhooks.
- OAuth internal operations.
- Workload identity federations.
- Dashboard.

## Management Port

- Health and readiness.
- OpenAPI JSON.
- Prometheus metrics.

For endpoint-level request and response details, use the API reference page.
