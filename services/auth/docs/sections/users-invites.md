# Users & Invites

Users are human accounts. Invites are controlled onboarding paths into a tenant.

## User Administration

- List users.
- Create users.
- View user detail.
- Edit users.
- Set user status.
- Set password.
- Force password change.
- Verify email or phone.
- Unlock account.
- Assign and remove roles.
- Link and unlink provider identities.
- Inspect devices, consents, sessions, and profiles.
- Revoke sessions.
- Start or administer erasure workflows.

## Invitations

- Create invites.
- View invite detail.
- Use public invite lookup for invite-registration screens.
- Register through an invite with pre-assigned roles.

## Self-Service Split

Administrators manage users from the console. Users manage their own profile, sessions, devices, account security, data export, erasure request, and linked identities from the hosted identity UI.
