# Account Self-Service

Account self-service belongs to the hosted identity UI and public identity API.

## Account Security

- Change email.
- Verify email change.
- Change username.
- Change password.
- Verify phone number.
- Delete account.

## Profiles

- Read default profile.
- Create or update default profile.
- Create multiple profiles.
- Edit profiles.
- Set default profile.
- Upload and delete profile pictures.

## Sessions And Devices

- List sessions.
- Revoke one session.
- Revoke all sessions.
- Revoke other sessions.
- List trusted devices.
- Delete trusted devices.

## Data And Identity

- Export account data.
- Request data erasure.
- Record consent.
- View linked identities.
- Link an upstream identity.
- Unlink an upstream identity.
