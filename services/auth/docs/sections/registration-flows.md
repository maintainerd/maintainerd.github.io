# Registration Flows

Registration flows define how users enter a tenant and which roles they receive.

## What A Flow Controls

- Whether registration is available.
- Which identity/provider context applies.
- What roles are assigned to newly registered users.
- Whether the flow is active or inactive.
- How invite-based registration maps into tenant access.

## Console Operations

- List registration flows.
- Create a registration flow.
- View a registration flow.
- Edit a registration flow.
- Change registration-flow status.
- Assign roles.
- Remove role assignments.

## Runtime Use

The hosted identity UI reads registration context so it can present the correct tenant, provider, and flow behavior to the user.
