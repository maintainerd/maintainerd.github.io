M9d Auth docs

Identity infrastructure for Maintainerd services and your applications.

Auth owns users, tenants, clients, OAuth flows, sessions, policies, API keys, MFA, and the identity surfaces needed by both built-in Maintainerd products and externally deployed applications.

OverviewAPI referenceService pageAll services

Service surfaces

maintainerd-auth

Backend identity service for setup, tenants, users, OAuth clients, API keys, roles, permissions, policies, sessions, MFA, and service authorization.

maintainerd-auth-console

Management console for administrators and developers to operate tenants, clients, users, policies, identity providers, and security settings.

maintainerd-auth-identity

Public-facing identity experience for login, consent, MFA, account flows, and OAuth user journeys.

Maintainerd services

Built-in services can depend on Auth for global policy checks, service clients, user identity, and tenant-aware access decisions.

Integration model

  • External applications identify through public client flows and can use Auth as their self-hosted identity provider.
  • First-party Maintainerd services use service authorization and tenant-aware policy checks.
  • Core can register services and surface Auth health, configuration, and operational status.

Deployment sketch

docker pull maintainerd/maintainerd-auth
