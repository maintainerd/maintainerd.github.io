# Workload Identity

Workload identity federation lets non-browser workloads authenticate without acting like users.

## Console Coverage

- List workload identity federations.
- Create a workload identity federation.
- View details.
- Edit configuration.
- Delete or retire configuration.

## Concepts

- A workload identity provider describes the external issuer or trust source.
- A service identity represents the local Auth side of the trust mapping.
- The result is a workload that can integrate with Auth-managed authorization.
